About This Project

Student Performance Prediction System

Project Overview

This system uses a Linear Regression machine learning model to predict student exam scores based on daily habits and lifestyle factors. The model was trained on a dataset of 1,000 students with 7 key features.

How It Works
  1. Enter your daily habits (study hours, sleep, exercise, etc.)
  2. The Linear Regression model processes your input against trained patterns
  3. Receive your predicted exam score (0-100 scale)
  4. Get personalized recommendations based on your habit patterns
Technology Stack
Backend Python, Flask
ML Model Linear Regression
Database SQLite3
Frontend Bootstrap 5, Chart.js

Model Interpretation

Positive coefficients indicate factors that increase predicted scores. Study hours and mental health have the strongest positive impact, while high social media and entertainment hours show negative correlation with exam performance.
